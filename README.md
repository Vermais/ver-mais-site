# Site Ver+

Landing page responsiva e acessível do projeto Ver+.

## Publicar uma nova versão do aplicativo

O site consulta automaticamente a release mais recente deste repositório e seleciona o primeiro arquivo `.apk`.

1. Abra **Releases** no GitHub e escolha **Draft a new release**.
2. Crie uma tag, por exemplo `v0.6.0`.
3. Anexe o APK, de preferência com um nome como `ver-mais-v0.6.0.apk`.
4. Publique a release.

O botão do site passa a oferecer a nova versão sem qualquer alteração no HTML. APKs grandes devem ser anexados à Release, pois arquivos acima de 100 MB não podem ser enviados diretamente ao repositório.
